# Supplemental language context for 2001 country interfaces

`country_languages_supplemental_context_2001.tsv` adds dated legal,
administrative, regional, and population-scope context for six game country
records without a usable national language description in the 2001 CIA World
Factbook. It does not change OpenPower's gameplay identity groups or treat
their estimated numeric population shares as measured census values.

The records are deliberately scoped to what each cited source establishes:

- **KOS:** UNMIK's 2000 Official Gazette rules name its publication languages.
  This does not estimate language use among Kosovo residents.
- **MNE:** the 1992 Republic constitution names Serbian in the Ijekavian
  dialect as official and gives Cyrillic and Latin equal status. The Council of
  Europe's 2002 report reproduces the constitutional provision.
- **SRB:** the 1992 Federal Republic of Yugoslavia constitution gives the
  federal official-language and script rule. This is a federal legal context,
  not a Serbia-specific census. It does not represent minority languages as
  absent.
- **SSD:** a 2001 Sudan assessment identifies prominent Nilotic peoples in
  Sudan's southern region and gives national language context. South Sudan was
  not a separate state in 2001; the source is not a separate-country language
  census or a complete list of languages.
- **TLS:** a U.S. Department of State report covering 2001 describes the draft
  official-language proposal and UNTAET's administrative languages. This is
  transitional-government context, not a final independent-state language law.

- **ATA:** the 2001 Factbook reports no indigenous inhabitants and a temporary,
  multinational research-station population. This supports treating the game
  language shares as scenario estimates, not a national resident-language
  distribution; it does not identify one language for Antarctica.
