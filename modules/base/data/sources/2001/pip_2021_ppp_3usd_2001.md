# World Bank PIP international poverty observations

This snapshot contains national Poverty and Inequality Platform (PIP) survey
records reported for 2001 at the current **$3 per person per day in 2021 PPP**
international poverty line. It is a separate metric from the country-specific
national-poverty estimates in `countries_historical.tsv`.

The PIP API request used version `20260922_2021_01_02_PROD`,
`reporting_level=national`, and `fill_gaps=FALSE`. The API returned 47 survey
records for 46 game-country IDs; Nicaragua has two records from the same survey,
one using consumption and one using income. Both are preserved in the row-level
ledger. The country extension uses consumption as its primary Nicaragua record
and stores the income estimate in separate alternate-value columns.

The importer accepts only records with reporting year 2001, a published survey
year within 2001, national reporting level and coverage, a $3 poverty line,
`estimation_type=survey`, and `is_interpolated=false`. The API's headcount is a
fraction; the extension stores it as a percentage. Fractional survey-year values
such as `2001.08` are retained as published. The API's income or consumption
welfare type, survey acronym, distribution type, PPP conversion factor, source
version, and direct query URL are retained for each observation.

PIP defines the international-line headcount as the share of people in
households with income or consumption per person below the threshold. It is a
whole-population measure, not an age-specific poverty rate. A modern PPP vintage
is applied retrospectively to 2001 household surveys; the result was not a
published $3-line statistic available in 2001. Income and consumption welfare
aggregates also differ by survey and are identified in the UI.

The snapshot records the API-supported game IDs and unsupported game IDs.
Unsupported IDs remain explicit unavailable rows in the country extension; a
missing survey result is never filled with zero or an adjacent-year estimate.
