# OpenPower First Playable Audit Closure

- **Audit source:** the attached `OpenPower_First_Playable_Audit.md`, dated 2026-11-14 and based on public `main` at `9b7a85fa`.
- **Implementation evidence date:** 2026-11-18, current local working tree. This is not evidence for a published commit.
- **Release scope:** single-player freeplay using the base module. English is sufficient for the first release. Network multiplayer and editor work remain outside this scope.

## Verdict

The audit's P0 direct-freeplay launch gate and P1 freeplay loop, feedback, and save/resume gates are closed by implementation and automated evidence. The game starts a selected country without a campaign or objective row, advances the world, accepts representative decisions, and resumes a freeplay save after a process restart.

The current Windows client was also launched through the main menu in this worktree. Its `OPENPOWER_UI_ARTIFACTS` capture reads the actual OpenGL framebuffer, so the globe, freeplay setup, selected-country map, and GameView are visible in stable snapshots such as `artifacts/ui/live-screen-diagnosis/actual-freeplay-current-1684x970.png` and `artifacts/ui/live-screen-diagnosis/actual-after-zoom-1280x720.png`. Windows Graphics Capture returns a blank image for this OpenGL window; that is a capture-path limitation, not a render failure. The live artifact writer now stages PNG frames and atomically replaces `actual.png`, so a concurrent reader sees a complete old or new frame instead of an in-progress write. A fresh process loaded this change and captured both the main menu and base-only USA freeplay screen. The stable copy `artifacts/ui/live-screen-diagnosis/actual-base-freeplay-atomic-20261118-1684x970.png` is a valid 1,126,943-byte PNG; its live report showed zero screenshot, telemetry, layout, or game errors.

The same framebuffer route now verifies the large Data Inspector view as well. `history_series_state` opened at 69,357 rows × 18 columns; searching `USA` showed USA records in the visible table, sorting by ID changed row order, and dragging the table scrollbar moved the visible rows. Screenshots include `artifacts/ui/live-screen-diagnosis/actual-data-inspector-history-usa-after-layout-fix-20261118-1684x970.png` and `artifacts/ui/live-screen-diagnosis/actual-data-inspector-history-usa-scrolled-20261118-1684x970.png`. Before the analyzer fix, clipped table-cell labels produced 615 false `text_overlap` findings because ImGui reports item bounds outside the visible column clip. `layout_checks.py` now skips pairwise text-overlap checks for text inside table regions, and the focused regression test passes. The live report now has zero layout findings, telemetry errors, or game system errors. The table stress sample measured frame interval p50 46.81 ms / p95 121.91 ms (240 samples) while live artifact capture was active; this is a diagnostic stress sample, not the 10,000-row target or slider acceptance, and the performance gate remains open.

The full audit is **not fully accepted yet**. Hands-on checks on target hardware, a long-run/battle-load performance gate, source-by-source fact checking of historical data, and the blinded participant study still need external evidence. The live capture verifies this machine's rendered frame and does not replace those gates.
